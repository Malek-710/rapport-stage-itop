En résumé

iTop est une solution open source de gestion des services informatiques (ITSM) et de gestion des configurations (CMDB) développée par Combodo. Elle centralise l'infrastructure IT, respecte les bonnes pratiques ITIL et est utilisée par des milliers d'entreprises — des PME aux grandes organisations.

F Principales fonctionnalités

  • Help Desk (tickets incidents & demandes)
  • CMDB complète (Configuration Items)
  • Change Management (gestion des changements)
  • Problem Management (gestion des problèmes)
  • IT Asset Management (actifs IT)
  • Gestion des services, contrats & SLA
  • Rapports, tableaux de bord & KPI
  • API REST & extensions/plugins

T Architecture technique

PHP MySQL / MariaDB Web AGPL

Application web accessible via navigateur. Déploiement sous Linux recommandé.

I Intégrations

  • Zabbix (supervision)
  • LDAP / Active Directory (auth)
  • Outils de supervision (alertes)
  • API REST (tout système externe)
